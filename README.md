# 🤖 Telegram Order Bot

Асинхронный Telegram-бот для автоматизации приема заявок и заказов, написанный на Python с использованием современной библиотеки **aiogram 3**. 

Бот проводит клиента по пошаговому сценарию заполнения брифа (FSM), сохраняет данные в локальную базу данных и моментально уведомляет администратора о новом заказе.

## Особенности
- **Асинхронность:** Быстрая обработка запросов благодаря `asyncio` и `aiogram 3`.
- **Машина состояний (FSM):** Удобный пошаговый сбор данных от клиента (Имя ➔ Задача ➔ ТЗ).
- **База данных SQLite:** Автоматическое сохранение всех заказов в легковесную БД без необходимости настройки серверов.
- **Уведомления админу:** Мгновенная пересылка сформированной заявки администратору в личные сообщения.
- **Безопасность:** Использование `.env` для защиты токенов и конфигураций.

## Технологии
- **Python 3.10+**
- **aiogram 3.x** (Telegram Bot API)
- **SQLite3** (База данных)
- **python-dotenv** (Управление переменными окружения)
