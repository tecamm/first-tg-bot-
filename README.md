# 🤖 Telegram Order Bot

Асинхронный Telegram-бот на базе `aiogram 3` для автоматизации приема заявок от клиентов. Бот пошагово собирает техническое задание, сохраняет данные в локальную базу данных и моментально уведомляет администратора, предоставляя удобный интерфейс для управления заказами.

## 🚀 Основной функционал

*   **Оформление заявок (FSM):** Пошаговый сбор данных (Имя ➔ Задача ➔ ТЗ) с встроенной валидацией длины текста и защитой от некорректного ввода.
*   **Управление заказами:** Клиенты могут просматривать список своих активных заявок (`/my_orders`) и самостоятельно отменять их через инлайн-кнопки.
*   **Админ-уведомления:** Моментальная отправка HTML-отчета администратору при создании нового заказа.
*   **Система банов:** Возможность для администратора заблокировать пользователя нажатием одной инлайн-кнопки (данные сохраняются в изолированную таблицу БД).
*   **Антиспам (Throttling Middleware):** Встроенная защита сервера от флуда сообщениями.
*   **Защита базы данных:** Ограничение на количество одновременно активных заказов (не более 2-х на пользователя).

## 🛠 Технологии

*   **Python 3.10+**
*   **aiogram 3**
*   **SQLite** 

## ⚙️ Установка и запуск (Локально)

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/tecamm/first-tg-bot-.git](https://github.com/tecamm/first-tg-bot-.git)
2. Cоздайте и активируйте .venv:
   ```bash
   python -m venv .venv
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
4. Создайте файл .env в корневой папке проекта и добавьте ваши ключи:
   ```bash
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_личный_telegram_id
5. Запустите бота:
   ```bash
   python bot.py
